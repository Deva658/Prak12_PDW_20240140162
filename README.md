# Tugas Frontend UI - AURA Perfumery
Project Landing Page dan Product Catalog dibuat menggunakan React, Vite, dan Tailwind CSS.

## Fitur Utama
- UI modern (Luxury Theme) menggunakan Tailwind CSS
- Responsive Design (Mobile & Desktop friendly)
- Cart State Management (Add/Remove item) menggunakan React Hooks
- Render data dinamis menggunakan Array of Objects
